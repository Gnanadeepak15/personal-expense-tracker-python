# Personal Expense Tracker using Python

## About the Project
A simple Python application to record and manage daily expenses.

## Features
- Add daily expenses
- View all recorded expenses
- Calculate total spending
- Save expense records using JSON

## Technologies Used
- Python 3
- Functions
- Lists and Dictionaries
- File Handling
- JSON

## How to Run
1. Install Python 3.
2. Download expense_tracker.py.
3. Open a terminal in the project folder.
4. Run:

python expense_tracker.py
